# Herramientas

Scripts de **solo lectura** para estudiar la pantalla del sistema (Windows, `pip install pywinauto`).
Úsalos si el sistema cambia o aparece un cuadro nuevo que PartesTeclea no conoce.

| Script | Para qué sirve |
|---|---|
| `grabadora_ingreso.py` | Observa mientras ingresas un parte a mano y anota campos, valores, teclas y avisos. |
| `recorrido_tab.py` | Anota el orden de los campos al avanzar con Tab (ejemplo: `ejemplo_recorrido_tab.txt`). |
| `diagnostico_ventanas.py` | Lista las ventanas y controles del sistema. |
| `exportar_lista.py` | Exporta a CSV la lista de un cuadro «Busca…» abierto. |
| `exportar_comunas.py` | Copia al portapapeles y guarda en Descargas la lista de comunas del sistema, tal como está guardada. |

Cada script explica su uso al empezar. Las grabaciones reales no se guardan aquí porque traen datos de personas.
